# 꼬리별 반려동물 호텔 — 어드민 (직원용)

가상의 반려동물 호텔 "꼬리별"에서 **직원**이 쓰는 화면입니다.

- 백엔드 저장소: `kkoribyeol-backend`
- 코어 웹 저장소: `kkoribyeol-web`
- 설계와 결정 이유: [설계.md](./설계.md)
- 디자인 규칙: [DESIGN.md](./DESIGN.md) (getdesign.kr의 여기어때 정리본을 그대로 따름)

> **백엔드가 무료 서버라 15분 쉬면 잠듭니다.** 처음 열 때 1분 가까이 걸릴 수 있어요.

## 화면

| 화면 | 하는 일 | 누가 |
| --- | --- | --- |
| 오늘 현황 | 오늘 들어오는 아이·나가는 아이. **사료와 알레르기를 함께 표시**하고 입실·퇴실을 처리합니다 | 직원 전체 |
| 예약 전체 | 모든 보호자의 예약을 상태·날짜·검색어로 찾고 상태를 바꿉니다 | 직원 전체 |
| 빈 방 | 날짜를 고르면 객실 종류별 빈 방 수를 보여 줍니다 | 직원 전체 |
| 보호자·반려동물 | **접종 만료 30일 이내** 목록과 보호자 검색(이름·연락처 뒷자리) | 직원 전체 |
| 직원 계정 | 계정 만들기·역할 바꾸기·사용 멈춤·비밀번호 리셋 | **관리자만** |

## 직원 계정 규칙

- 직원은 **회원가입이 없습니다.** 관리자가 어드민에서 만듭니다.
- 계정을 만들거나 비밀번호를 리셋하면 **임시 비밀번호**가 한 번만 나옵니다.
- 임시 비밀번호로 로그인하면 **비밀번호를 바꾸기 전까지 다른 화면을 쓸 수 없습니다.**
- 사용을 멈춘 계정은 로그인할 수 없고, 이미 로그인해 둔 창도 바로 막힙니다.

## 확인용 관리자 계정

보안을 위해 저장소에 적지 않았습니다. **과제 제출 폼에 따로 적어 냈습니다.**
